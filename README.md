# micxio — โปรแกรมดัดเสียง

โปรแกรมเดสก์ท็อปสำหรับเปลี่ยนลักษณะเสียงพูด เช่น เสียงผู้ชายเป็นเสียงผู้หญิง เสียงโรบอท หรือเสียงปีศาจ โดยประมวลผลภายในเครื่องและไม่ต้องอัปโหลดเสียง

## ความสามารถ

- เอฟเฟกต์ 12 แบบ: ผู้หญิง ผู้ชาย เด็ก เด็กผู้ชาย เด็กผู้หญิง ผู้สูงอายุชาย ผู้สูงอายุหญิง โรบอท ปีศาจ เอเลียน วิทยุ และเสียงก้อง
- บันทึกเสียงจากไมโครโฟนแบบเรียลไทม์ พร้อมตัวจับเวลาและมิเตอร์ระดับเสียง
- เมื่อหยุดบันทึก ไฟล์จะถูกเพิ่มเข้ารายการเพื่อดัดเสียงต่อทันที
- โหมด Live Voice: ส่งเสียงไมโครโฟนผ่านเอฟเฟกต์ที่เลือกไปยังหูฟัง/ลำโพงแบบเรียลไทม์
- ปรับความเข้มของแต่ละเอฟเฟกต์ได้ 0–100%
- เปลี่ยน Pitch และ Formant โดยรักษาความยาวของเสียงเดิม
- บันทึกผลลัพธ์เป็น MP3, WAV หรือ FLAC
- ประมวลผลหลายไฟล์ต่อเนื่อง พร้อมแสดงความคืบหน้าและยกเลิกงานได้
- ดับเบิลคลิกไฟล์ที่ทำเสร็จแล้วเพื่อเปิดฟังทันที
- ไม่เขียนทับไฟล์ต้นฉบับหรือไฟล์เดิม
- เปลี่ยนภาษาได้ทันที: English (ค่าเริ่มต้น), Русский, 简体中文 และ 日本語

## เริ่มใช้งาน

### Linux

ดับเบิลคลิก `run.sh` หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```bash
./run.sh
```

### Windows

ดับเบิลคลิก `run.bat` (ต้องติดตั้ง Python 3 ไว้ก่อน)

การเปิดครั้งแรกจะดาวน์โหลดเอนจินประมวลผลเสียง FFmpeg โดยอัตโนมัติ หลังจากนั้นใช้งานแบบออฟไลน์ได้

## ใช้งานแบบนักพัฒนา

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

รันชุดทดสอบ:

```bash
.venv/bin/python -m unittest discover -v
```

## หมายเหตุ

- ไฟล์ต้นฉบับที่รองรับ ได้แก่ MP3, WAV, FLAC, OGG, M4A, AAC, OPUS, WMA, AIFF, AC3, WebM และ MP4
- เสียงจากไมโครโฟนถูกบันทึกแบบเรียลไทม์ลงในโฟลเดอร์ `recordings`
- เอฟเฟกต์จะถูกประมวลผลหลังจากกดหยุดบันทึก เพื่อหลีกเลี่ยงเสียงหน่วงและเสียงย้อนเข้าลำโพง
- โหมด Live Voice ควรใช้หูฟังและเริ่มจากระดับเสียงต่ำ เพื่อป้องกันเสียงหอนจากไมโครโฟนเข้าลำโพง
- คุณภาพของเสียงผู้หญิง/ผู้ชายขึ้นอยู่กับระดับเสียงและลักษณะเสียงต้นฉบับ ควรลองปรับความเข้มประมาณ 45–75%
